# Phishing Educativo

Una demo educativa para mostrar cómo se ve un correo de phishing y cómo reconocerlo antes de hacer clic.

## Ver la demo

Para abrir directamente el correo educativo en el navegador, hacé clic aquí:

[**Abrir demo en el navegador**](./phishing_educativo.html)

Si querés verlo online, una vez que GitHub Pages esté activado, la URL será:

https://Mati830.github.io/Phishing-Material-Educativo/phishing_educativo.html

> Esto abre la vista real del mail, no el repositorio.

## Qué hace esta demo

- muestra un correo falso parecido a un banco
- incluye un enlace sospechoso
- dispara una alerta falsa para crear presión
- explica por qué ese mensaje es un phishing
- enseña cómo detectar señales de riesgo

## Cómo abrirla sin usar VS Code

Si una persona no es programadora, lo más simple es:

- abrir la carpeta del proyecto
- hacer doble clic en `phishing_educativo.html`
- o arrastrarlo a una pestaña del navegador
